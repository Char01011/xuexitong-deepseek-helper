# 学习通视频与章节测验助手（Edge 油猴 / 控制台）

当前为 V4.7.5，提供油猴入口：不用打开 F12，页面右下角显示视频、题目识别、答案请求批次和错误，并提供“查看识题诊断”按钮。原控制台入口也保留，两种入口使用同一份播放和答题代码。DeepSeek API Key 输入到本地服务的窗口中，不会写入脚本或保存到文件。

## 推荐使用：油猴入口

1. 如果当前正显示“在 debugger 语句处暂停”，先到 Sources（源代码）工具栏点击 **Deactivate breakpoints（停用断点）**，再按 **F8** 恢复运行，然后关闭开发者工具。停用“遇到异常时暂停”是另一个设置，不能代替这一步。已在正常运行的控制台脚本可以继续运行，通常不需要刷新。
2. 准备切换入口时，关闭旧的“学习通自动任务辅助窗口”和旧本地服务；在油猴中停用此前的 V3 / 其他学习通脚本。
3. 运行当前 `deepseek-console` 文件夹里的 **`start-local-service.cmd`**，输入 API Key，等到“本地服务已启动”。保持该窗口打开。启动时会同时更新 `xuexitong-console.js` 和 **`xuexitong-deepseek.user.js`** 的临时连接令牌。
4. 用记事本打开 **`xuexitong-deepseek.user.js`**，Ctrl+A、Ctrl+C。点击 Edge 的油猴图标 → 管理面板 → 新建脚本，Ctrl+A 替换默认内容，粘贴后按 **Ctrl+S** 保存。脚本名为“学习通视频与章节测验助手 DeepSeek”。如果之前已安装过这个脚本，编辑原脚本并替换全部内容即可，避免重复安装。
5. 确认油猴允许访问学习通，并已启用 Edge 扩展详情页的“允许用户脚本”（没有该选项时按油猴提示启用开发者模式）。关闭 F12，回到包含左侧课程目录的课程页，刷新一次。右下角出现 **“学习通 DeepSeek V4.7.5”** 和当前步骤即表示入口已执行。

油猴会在课程整页跳转后重新执行入口；内嵌视频或测验的切换继续由既有页面检查处理，不再需要小辅助窗口。只有最外层课程页会启动控制器，题目 iframe 不会重复启动。

**每次重启本地服务后，必须重新把新生成的 `xuexitong-deepseek.user.js` 全文保存到油猴，再刷新课程页。** 文件中的临时令牌每次启动都会改变，油猴不会自动读取磁盘上的新文件。只改磁盘文件不更新油猴编辑器，会显示“本地连接令牌已更新”。脚本不包含 DeepSeek API Key。

该入口不修改网页的 `debugger` 语句，也无法替浏览器恢复调试暂停。它使日常运行无需打开开发者工具；如果重新打开 F12，网页的 `debugger` 仍可能暂停，需要恢复执行或停用断点。

### 题量不完整，例如识别 35 / 总共 40 题

V4.7.2 增加“查看识题诊断”按钮，并兼容题型标签两侧含空格或拆在多个 span 中的情况。缺题时仍会停止，不会忽略剩余题目提交。点击状态框下方按钮，在弹出文本框按 Ctrl+A、Ctrl+C 复制诊断。诊断包含已识别数量、题型数量、遗漏题号、暂不支持的题型、缺少选项或输入框、文本超限与编辑器未加载等原因；无法定位题型标记的题目计入 `unaccountedQuestions`。诊断不包含题干、选项正文或连接令牌，不能保证仅凭题量差值就定位全部结构问题。

此次网页端更新可直接连接已经运行的 V4.7.1 / 接口版本 2 服务；保持当前服务窗口打开，把新生成的 `xuexitong-deepseek.user.js` 全文替换进油猴并保存，再刷新课程页即可。构建脚本保持文件中的现有连接令牌，不需要为此重启服务。如果主动重启服务，仍需在启动完成后重新更新油猴中的文件内容。控制台版也可只读调用 `window.top.__xuexitongConsoleDeepSeek.inspectQuizDiagnostics()`。

### 填空题标签已找到，但没有找到输入框

V4.7.3 将填空题容器查找从固定 9 层改为最多 64 层，遇到多道题的容器或文档根节点就停止。在同一道题内找到全部字段后，使用同时包含题型标签与这些字段的最小容器，避免吞入页脚或相邻题目的输入框。还增加 `contenteditable="plaintext-only"` 可编辑区域的识别；仍要求浏览器报告该区域可编辑，不会把隐藏、只读、禁用或编辑器工具栏中的控件当作答案框。[可编辑区域格式说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable)

如果仍找不到字段，诊断中的 `blankDiscovery` 会记录查找层数、停止原因和最多 20 个控件的类型、可见性、只读/禁用/可编辑状态，不包含输入内容、控件名称或网址。`position` 是扫描到的题型标签顺序，可在页面题号无法读取时帮助定位。这些兼容修复经过本地模拟检查，实际课程页是否使用这些结构仍需现场确认；题量不足时仍停止。

### UEditor 的编辑区可输入，但 iframe 被判为不可见

V4.7.4 先核对 iframe 对应的既有编辑器实例，再进行普通控件的可见性筛选。隐藏的 UEditor 框架只有在实例明确 ready、body 可编辑、框架绑定一致且不在源码/只读状态时，才通过实例的 `setContent()` / `sync()` 处理。不会新建猜测 ID 的编辑器，也不会将任意隐藏 textarea 当作答案框。写入前重新核对各空和实例身份；写入后核对编辑器文本，存在可验证的提交字段时还会比较同步内容。[UEditor 官方实现](https://github.com/fex-team/ueditor/blob/dev-1.5.0/_src/core/Editor.js)

带 UEditor 特征但尚未匹配实例的框架计入待就绪空位，避免只计当前可见的一个空就开始答题。诊断的 `recognized` 中增加每题 `blankCount` / `pendingBlanks`；待就绪详情包含具体原因，状态框显示待就绪空数。多空、编辑器身份变化、同步失败及隐藏编辑区的换行回读经过本地模拟检查，仍需实际课程验证。本次客户端仍兼容正在运行的 V4.7.1 / 接口版本 2 服务，可保持当前服务不重启，直接替换油猴中脚本全文并刷新课程页。

V4.7.5 修复就绪标记的类型兼容错误：UEditor 官方初始化代码赋值 `isReady = 1`，V4.7.4 对隐藏实例只接受 `true`，会将该官方数字标记误判为尚未完成初始化。现在同时接受数字 `1` 和布尔 `true`，数字 `0`、布尔 `false` 仍阻止答题。模拟 UEditor 默认也改用官方的数字 `1`，并分别验证可填写、未就绪、只读、源码模式及同步失败。待就绪诊断另含标记类型与布尔/数字值，其他类型不输出原始内容。[官方就绪逻辑](https://github.com/fex-team/ueditor/blob/dev-1.5.0/_src/core/Editor.js)

### “本地服务接口版本不匹配”

这个错误表示浏览器连到的正在运行的服务没有接口版本 2。只更新磁盘文件不会更新旧进程。关闭旧服务窗口后，再从当前 D 盘目录运行 `start-local-service.cmd`；必须看到 **“本地服务已启动”**、**“服务版本：4.7.5，接口版本：2”**，然后再更新油猴内容或复制控制台 JS。V4.7.1 起会在输入 API Key 前先占用端口；若提示“37841 端口已被旧服务占用；本次新服务未启动”，就还没有成功切换服务，不要继续复制脚本。

### 油猴提示“此脚本还未被执行”

若已确认课程网址匹配、扩展启用、允许用户脚本且有当前网站访问权限，可临时停用主脚本，将同目录 `tampermonkey-check.user.js` 全文保存为新的油猴脚本，并确认油猴菜单的总开关和自检脚本开关已启用，再刷新课程页。自检脚本使用相同的匹配规则和执行模式，只在左上角显示绿色“油猴自检成功”提示，不依赖本地服务，不操作课程或题目。有绿色提示时继续排查主脚本启动；无提示时继续检查油猴整体执行、脚本启用状态和注入环境，不应据此认定是 API Key 或本地服务故障。检查完成后停用自检脚本。

## 可选使用：控制台入口

1. **停用此前安装的学习通油猴脚本**，避免它与控制台版同时操作页面。
2. **先将 ZIP 全部解压到同一个文件夹**，不要直接从压缩包内运行文件。双击解压后文件夹里的 **`start-local-service.cmd`**。在黑色窗口粘贴 DeepSeek API Key，按 Enter。输入过程不显示字符。窗口显示“本地服务已启动”后保持它打开。
3. 用记事本打开同目录的 **`xuexitong-console.js`**，按 **Ctrl+A、Ctrl+C** 复制完整文件。它是缩短缩进后的控制台复制版；不要从聊天窗口的代码预览中复制片段。
4. 在 Edge 中打开学习通课程播放页，按 F12 → Console，粘贴脚本，按 Enter。脚本会打开一个小的“学习通自动任务辅助窗口”；请保持这个窗口打开。它用于在“下一节”触发整页跳转后重新启动控制台脚本。随后可以关闭开发者工具，返回课程页。

辅助窗口只能访问与它同源且可访问的课程页。遇到临时跨域跳转时，V4.7.1 会提示等待，返回原课程页后恢复；若新页面持续不可访问，控制台入口无法自动跨域注入，请改用油猴入口。[浏览器同源限制](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)仍然适用。新版辅助窗口检测到油猴入口启动时会自行退出；已打开的旧版辅助窗口需要手动关闭一次。

每次关闭本地服务窗口后再次运行，都需要重新输入 API Key，并重新复制一次 `xuexitong-console.js`。本地服务每次启动都会更新脚本中的临时连接令牌。

如果服务退出，窗口会停在“请按任意键继续”。请查看上方的报错文字。`start-local-service.cmd`、`deepseek-local.mjs`、`deepseek-request.mjs`、`build-userscript.mjs` 和 `xuexitong-console.js` 必须在同一文件夹内。

## 自动流程

- 视频页：默认使用 1 倍原速；同页上下排列的多个可访问视频按页面顺序播放，全部结束后再点击下一步。隐藏或无法访问的播放器不在此范围内，尚未加载出来的视频也可能需要人工检查。可在 `xuexitong-console.js` 搜索 `playbackRate: 1` 修改默认倍率，`1` 为原速。配置会在开始播放、视频加载完成和恢复播放时应用；播放器拒绝设置时保留当前倍率。控制台显示的是播放器当时的实际倍率，平台仍可能限制倍率或任务点记录。
- 章节切换：识别“下一节”“下一章”“下一小节”“下一章节”“下一步”等可用按钮，通过课程节点、内嵌页面或视频来源是否变化确认切换；支持新旧两步都为视频的情况，不再要求页签类型必须改变。若点击后仍是旧内容，会继续等待，超时后停止并报错。
- 自动播放：V4.2 会先把当前视频及其外层 iframe 滚动到可见区域，优先调用已存在的 Video.js 播放器接口；没有对应实例时才用原生视频接口。只有监测到实际时间进度前进，才确认播放已恢复。连续三次请求仍无进度会停止；单次播放请求等待最多 5 秒。浏览器返回 `NotAllowedError` 时直接提示需要点击播放，不会继续循环请求。页面在后台时暂缓恢复，回到前台后再尝试。浏览器或平台明确要求用户操作的情况，脚本无法保证免点击启动。
- 练习页：V4.3 优先识别课程内 `doHomeWorkNew` / `doHomeWork` 框架，避免外层仍显示“视频”时卡在切换等待。读取题目前跳过尚未生成 body 的框架，单个加载中的框架不会中断其他框架的识题。视频自动播放失败的状态不会阻止进入测验处理。
- 自动接管：V4.4 增加独立于视频播放的页面状态检查。课程自身切换 iframe、没有触发点击或视频结束事件时，识别到尚未开始的练习也会自动进入答题流程。正在处理的测验不会重复启动，同页已停止的失败任务不会自动循环重试；进入新的可播放视频步骤后才重新准备下一轮。诊断结果的 `quiz.watcherActive` 表示该检查是否已启用。
- 判断题与题量：V4.5 支持没有 A/B 字母、以“正确/错误”或“√/×”等表示的判断选项，按实际选项元素选择；内部统一使用 A=正确、B=错误，页面选项顺序可以相反。题干按选项前的页面内容读取。整套题必须先通过题量核对，再按每批 10 题顺序请求答案；所有批次都通过校验后才开始选择和提交。某一批失败时不会提交部分答案。诊断结果中 `recognizedByType` 显示识别到的题型数量，`currentBatch` / `totalBatches` 显示请求进度。
- 多空填空题：V4.6 按页面顺序识别一题内的多个可编辑输入框，题干中的输入位置以 `[第1空]`、`[第2空]` 等表示，保留各空后续的题干。支持普通文本输入框、textarea、普通可编辑区域，以及能够定位已有实例的 UEditor/TinyMCE；无法识别的富文本编辑器会停止处理。模型按每空一个字符串返回答案，少空、空答案、超出字段长度限制、输入框发生变化或填写结果未保留时均停止提交。全部题目答案通过校验后才开始写入，填写结束还会再次核对全部填空。
- **更新到 V4.6 时必须重启本地服务**：同时更新了 `deepseek-local.mjs` 与 `deepseek-request.mjs` 的填空请求格式和提示词。先关闭旧辅助窗口和旧服务，用同目录 `start-local-service.cmd` 重新启动；服务启动后再复制新的 `xuexitong-console.js`，在最外层课程页（top）执行。不要混用 C 盘旧服务与 D 盘新版脚本。
- V4.6.1 的脚本和本地服务必须配套更新：启动时确认接口版本，并显示服务版本。旧服务未关闭或端口占用时会明确提示，不会先请求部分答案才发现题型不兼容。修复了按网络分块读取时可能损坏中文的 UTF-8 解码问题。格式校验仍保留，失败时指出本批题号和字段，并返回 422；AI 服务调用失败返回 502。`inspectFlow()` 另含 `scriptVersion`、`service` 和 `quiz.lastRequest`，后者只记录题型、题干长度、选项长度和空数，不记录题干正文。
- 测验页：滚动题目区域、识别实际出现的单选、多选、判断和填空题，调用 DeepSeek 并选择选项或填写输入框；核对题量后点击“提交”，处理学习通弹出的二次提交确认，等“本次成绩”或当前章节的完成标记出现后点击页面下方的“下一节”，进入新视频并开始下一轮任务。如果从已完成的测验页启动脚本，也会直接进入下一节。
- 使用 DeepSeek API 的 `deepseek-flash` 模型名（对应 DeepSeek V4.1 Flash），开启低强度思考，每批答案输出限制在 8000 tokens；若仍超限则停止，不会提交截断答案。
- 题目文字若受学习通防复制处理，出现替换字或夹杂字符，提示词会要求模型结合题意和选项在内部推断原句再作答；控制台打印的是页面读出的原始文字，推断仍可能有误，请核对题目和选项。
- 题目分批请求，并使用简短提示词；输入题目内容不做截断。提示词要求每题都返回有效选项，不确定时选择最可能答案，避免空答案触发格式校验。
- 控制台会打印发送给 DeepSeek 的题干和选项；题目图片和题目卡片外的材料不会发送，遇到图表题或依赖前文的题目请先核对 `app.inspectQuiz()` 的识别结果。
- 视频会在播放前、以及恢复播放前主动设置静音。若页面播放器使用独立音频通道或重新创建了播放器，仍可能需要检查网站播放器本身的静音状态。
- 点击下一步后最多等待 120 秒确认新内容加载；测验提交按钮和题目分别最多等待 120 秒。提交后持续等待成绩页，不会因出分慢而提前停止；每 15 秒在控制台显示一次等待进度。需先关闭辅助窗口，再刷新课程页以停止页面脚本。
- 页面结构、题量、选项、接口或提交结果不符合预期时停止并在控制台显示原因。
- 如果回答被截断或 JSON 为空，本地服务会报告失败；不会拿残缺答案提交。

浏览器可能询问是否允许该课程页访问本地网络；此请求用于连接电脑上运行的本地服务。若被浏览器策略或页面策略阻止，控制台会显示连接错误，脚本不会继续自动答题。若 Edge 阻止了小辅助窗口，请允许 `mooc1.chaoxing.com` 打开弹出窗口后重新运行脚本；否则整页跳转后需要手动在新页面重新粘贴脚本。

题目和选项会发送至 DeepSeek API，调用可能产生费用，模型也可能答错。已在当前课程页确认题目识别、DeepSeek 调用、二次提交确认、100 分成绩页及“下一节”到新章节的跳转；整页跳转后的辅助窗口自动恢复经过模拟测试，尚未在真实课程页完成连续运行验证。首次使用请观察一次完整流程。

## 本地检查

在项目根目录运行 `node deepseek-console/build-userscript.mjs` 生成油猴文件，再运行 `node --check deepseek-console/xuexitong-console.js` 和 `node tests/deepseek-flow.mjs`。后者使用模拟页面和模拟 AI 响应验证视频队列、章节切换、混合题型、多空填写、失败不提交及油猴启动行为。`node tests/navigation-keeper.mjs` 检查跨域等待、同源返回和入口接管；`node tests/local-service-startup.mjs` 在临时端口验证占用时不索要密钥、不修改文件，以及新服务的版本和启动文件一致。这些检查不连接学习通或 DeepSeek，不能替代真实课程的连续运行验证。新增油猴入口尚需在实际 Edge 课程页面确认。

如果页面顶部出现黄色的“已在调试程序中暂停”，先看暂停原因：**Paused on debugger statement** 时，使用 Sources 工具栏的 **Deactivate breakpoints（停用断点）**，再按 **F8** 或点击“恢复脚本执行”（▶）。如果是 **Paused on exception**，再检查右侧“遇到已捕获 / 未捕获异常时暂停”的选项。随后关闭开发者工具，页面脚本仍会继续运行，通常无需刷新。暂停期间网页和自动脚本都不会继续执行，延长等待时间也无效。控制台的 `work-css-tpl.cssx 404`、`highlight.js deprecated`、`JQMIGRATE` 是学习通页面资源或库的提示，不能单凭这些判断自动脚本失败；请查看是否还有“切换下一学习步骤失败”或“章节测验自动作答停止”的具体错误。

如果控制台显示 `Uncaught SyntaxError: missing ) after argument list`，通常表示粘贴内容被截断或混入了别的文字。请从解压后的 JS 文件用 Ctrl+A、Ctrl+C 重新复制，粘贴后先检查控制台输入末尾是否为 `})();`，再按 Enter。

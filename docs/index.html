01 / 先认识这个项目

它由三个部分配合工作。

油猴负责在课程页启动脚本，本地服务负责连接模型，DeepSeek 根据题目文字返回答案。

A

Edge 中的脚本

发现视频和章节测验，识别单选、多选、判断与一题多空的填空题，处理章节切换。

B

电脑上的本地服务

运行在 127.0.0.1:37841。API Key 在这个窗口输入，保存在当前进程内存中。

C

DeepSeek API

接收题干、选项和空数。答案通过格式、数量和填写结果核对后，脚本才继续提交。

开始前了解

题目文字会发往 DeepSeek，API 调用可能计费，模型也可能答错。首次使用请观察一整轮流程，并遵守课程对辅助工具的使用要求。图片题、简答题和未知编辑器不保证支持。

03 / 准备运行环境

先准备好这四样。

01

Windows 电脑与 Edge

教程使用普通浏览窗口。登录自己的学习通，进入带左侧章节目录的课程页。

02

Node.js 的 LTS 版本

前往 Node.js 官网 ↗，安装标有 LTS 的 Windows 安装程序。默认选项通常即可，安装后重新打开命令窗口。

node -v

看到 v... 版本号，表示系统可以找到 Node.js。无需运行 npm install。

03

油猴扩展 Tampermonkey

从 油猴官方 Edge 安装入口 ↗ 安装。在扩展详情中启用“允许用户脚本”，并允许访问实际使用的学习通站点。

04

可用的 DeepSeek API Key

在 DeepSeek 开放平台 ↗ 获取自己的 API Key，确认账号可以调用 API。聊天网页能使用，不代表 API 账号一定可用。

参考：油猴用户脚本权限 · DeepSeek API 文档

04 / 一步步部署

按顺序做，完成一项勾一项。

推荐油猴路线：配置一次后，课程页会自动启动脚本，日常运行可以关闭 F12。

已完成 0 / 7 项
01完整解压项目文件＋

ZIP → 右键“全部解压” → 打开解压后的完整文件夹。不要在压缩包预览中直接双击启动文件，也不要单独移动 CMD。

成功信号能看到 START.cmd 和 deepseek-console 文件夹。

02启动本地服务，输入 API Key＋

双击根目录 START.cmd，或进入 deepseek-console 双击 start-local-service.cmd。在黑色窗口粘贴自己的 API Key，按 Enter。输入时没有字符和星号回显是正常的。

本地服务已启动：http://127.0.0.1:37841
服务版本：4.7.5，接口版本：2

看到以上信息后保持窗口打开。若提示端口被占用，本次新服务没有启动，先关闭旧服务窗口再重试。

03打开正确的学习通课程页＋

登录学习通 → 进入课程 → 打开章节学习页面。页面通常带左侧章节目录；地址路径含 /mycourse/studentstudy，也支持 /mooc2-ans/mycourse/studentstudy。

保留完整地址供自己使用即可，反馈问题时只需提供域名和问号前的路径。直接单独打开的题目 iframe 不是主脚本的启动入口。

04允许油猴执行用户脚本＋

Edge 地址栏输入 edge://extensions/ → 找到 Tampermonkey → 详细信息 → 开启“允许用户脚本”，站点访问中允许当前课程域名，例如 https://mooc1.chaoxing.com/*。

若当前版本没有“允许用户脚本”，按油猴官方说明在扩展管理页启用开发者模式。设置好后仍可以保持 F12 关闭。

05复制服务刚生成的油猴脚本＋

在本次启动服务的同一个文件夹里，用记事本打开 xuexitong-deepseek.user.js，按 Ctrl+A、Ctrl+C 复制全文。务必先启动服务，再复制这个文件。

选对文件油猴入口是 xuexitong-deepseek.user.js。xuexitong-console.js 是另一个控制台入口。

06在油猴中首次新建并保存＋

Edge 扩展图标 → 油猴 → 管理面板 → ＋／添加新脚本。点击代码区域，Ctrl+A 选中默认模板，Ctrl+V 粘贴完整文件，Ctrl+S 保存。

首次操作是“新建脚本”；以后更新则编辑这一条现有脚本。确认名字是“学习通视频与章节测验助手 DeepSeek”，脚本开关和油猴总开关均已启用。停用其他会操作同一课程的学习通脚本。

07刷新课程页，观察第一轮＋

关闭 F12，回到课程页按 F5。右下角应出现“学习通 DeepSeek V4.7.5”。先观察一次完整的视频 → 测验 → 下一节流程；浏览器要求用户操作时，按提示点击播放。

成功信号视频时间实际前进；测验题量完整、待就绪空数为 0，随后进入答案请求批次。

每次重启本地服务后

重新复制新生成的 .user.js → 替换油猴里现有脚本全文 → Ctrl+S → 刷新课程页。每次启动都会更换临时连接令牌，油猴不会自动读取磁盘文件的变化。

05 / 确认运行正常

读懂状态，比反复刷新更有用。

视频

进度条和时间持续前进
一次 play() 请求成功，并不等于视频真的播放。浏览器拦截自动播放时需要手动点击一次。

识题

题量完整，而且所有空位都就绪
例如 40/40 只说明题目数量齐了；若仍有“等待编辑器就绪”，脚本会继续等待。

请求

显示第几批 / 共几批
前端每批最多 10 题，按顺序请求。某批处理过程中保持服务打开，避免刷新打断。

提交

全部答案校验、填写回读后再提交
脚本会处理提交确认，等待成绩或完成标记，再进入下一学习步骤；模型正确率不保证。

停止与恢复

需要停止时，在油猴中停用主脚本并刷新课程页，再关闭本地服务。控制台旧入口还要先关闭小辅助窗口。恢复时重新按启动顺序操作。

06 / 遇到问题怎么办

按眼前的现象，找下一步。

先记录版本、状态文字和卡住的位置。无需提供 API Key、连接令牌或完整课程地址。

油猴显示“此脚本还未被执行”，没有状态框

核对脚本已保存、油猴内部总开关、用户脚本权限、当前域名和主脚本开关。关闭再开启整个油猴扩展，新建课程标签页测试。可将包内 tampermonkey-check.user.js 临时保存为自检脚本，检查左上角绿色提示；自检后停用它。仍无提示时记录 Edge／油猴版本和完整菜单状态。

“本地连接令牌已更新”

服务保持当前窗口运行，从这个服务目录重新复制生成的 .user.js，替换油猴中的旧副本并保存，再刷新课程页。不要为了更新脚本又重启服务，否则令牌会再次变化。

“接口版本不匹配”或“37841 端口已被占用”

磁盘上的新文件不会更新已经运行的旧进程。关闭旧服务，用当前完整目录重新启动；看到服务版本和接口版本后，再复制脚本。显示端口占用意味着本次新服务没有成功启动。

切到测验时出现“在 debugger 语句处暂停”

进入开发者工具的“源代码／Sources”，点击工具栏“停用断点”，再按 F8 恢复。随后关闭 F12。网页暂停时脚本也不能执行，延长等待时间无效。日常使用推荐油猴入口。

识别 35/40，或等待 120 秒仍不完整

点击状态框“查看识题诊断”，在弹出文本框 Ctrl+A、Ctrl+C 复制结果。查看 rejected 和 unaccountedQuestions，可区分题型不支持、缺少选项／输入框、文字超限等情况。不要修改总题量来绕过完整性核对。

已经 40/40，却一直等待填空编辑器

查看 pendingEditors 的每空原因。V4.7.5 同时支持 UEditor 的数字 1 和布尔 true 就绪标记，修复 V4.7.4 的兼容判断。未知实例、未就绪、只读或源码模式仍会阻止提交。

请求答案出现 422、502 或 API 错误

422 通常是本地请求格式校验不通过，查看具体题号与字段；502 表示本地服务调用模型失败，需看返回的具体原因。401／余额或限流提示则按开放平台说明核对账号。不要仅凭 HTTP 状态码认定是同一个原因，也不要公开密钥。

视频未自动开始，或同页有多个视频

默认 1 倍速、静音，按可访问视频的页面顺序处理。状态中的播放器请求成功不代表实际前进；脚本会观察进度并限制恢复尝试。浏览器要求交互时手动点击播放，保持课程页前台检查。平台限制与尚未加载的隐藏视频仍可能需要人工处理。

控制台有 CSS 404、highlight deprecated 或 JQMIGRATE

这些是网页资源和库的提示，不能单凭它们判断助手失败。优先看状态框中的具体错误、识题诊断及本地服务输出。

状态框提示连接失败 / Failed to fetch

确认服务窗口仍运行且本次启动成功；若浏览器询问课程页访问本地网络，请按自己对该项目的信任决定授权。单位电脑或浏览器策略限制连接时，脚本无法继续请求答案；保留具体错误再排查。

旧辅助窗口提示跨域，不能读取 href

旧控制台辅助窗口受浏览器同源规则限制。油猴入口由扩展在匹配的新课程页重新启动，不依赖这个小窗口；迁移后关闭旧辅助窗口。控制台模式跨域后可能需要在可访问的原课程页重新运行。

没有匹配项。请保留状态文字，在项目反馈中说明版本、操作顺序和诊断结果。
